Gestión Salud

Resumen de módulos, estado y próximos pasos — 23 de agosto de 2026

La plataforma integra aplicación Expo para móvil/web, API NestJS y SQL Server para el manejo de información clínica, bienestar y colaboración médica.

Módulos disponibles

Acceso y cuentas

Registro, autenticación JWT, recuperación de contraseña, biometría compatible y roles.

Pacientes y expediente

Perfiles, personas asociadas, resumen clínico, alergias, antecedentes, exámenes y documentos.

Atención médica

Consultas, citas, vacunas, medicación, condiciones crónicas, embarazo y registros clínicos.

Bienestar y Nano

Hábitos, seguimiento físico, salud mental, período, educación y asistente Nano.

Colaboración médica

Solicitud de médico, permisos temporales, QR y enlaces para historial compartido.

Administración y Premium

Clínicas, instituciones, catálogos, solicitudes, pagos y suscripciones.
